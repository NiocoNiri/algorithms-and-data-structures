# Бинарное дерево поиска и тесты

Python 3.10 или новее. Сторонние библиотеки не нужны.

## Запуск

Открой терминал VS Code в папке с этими файлами:

```powershell
python binary_tree.py
python -m unittest -v
```

В Windows вместо `python` также можно использовать `py`.

## Пример

```python
from binary_tree import BinarySearchTree

tree = BinarySearchTree([12, 6, 17, 3, 7, 15, 31, 9])
tree.insert(8)
print(tree.search(9).value)  # 9; для отсутствующего значения search вернёт None
print(100 in tree)          # False
print(tree.inorder())       # [3, 6, 7, 8, 9, 12, 15, 17, 31]
print(tree.delete(12))      # True
print(tree.delete(100))     # False
print(len(tree))           # 8
```

## Правила и методы

Это обычное BST без автоматической балансировки, не АВЛ-дерево.
Для каждого узла все значения слева <= его значения, справа строго >.
Повторы хранятся отдельными узлами; delete удаляет ровно одно вхождение.
Используй взаимно сравнимые значения одного типа, например целые числа
или строки. Смешивание чисел и строк, NaN и несогласованные сравнения
не поддерживаются. Не изменяй root и найденные узлы извне.

| Метод | Результат |
|---|---|
| insert(value) | Добавляет элемент, возвращает None |
| search(value) | Узел или None |
| value in tree | True / False |
| delete(value) | True при удалении, False при отсутствии |
| minimum(), maximum() | Значение; ValueError для пустого дерева |
| inorder() | Список: лево — узел — право, по возрастанию |
| preorder() | Список: узел — лево — право |
| postorder() | Список: лево — право — узел |
| len(tree) | Количество элементов с повторами |

Поиск, вставка, удаление, минимум и максимум: O(h), где h — высота.
При хорошей форме дерева это O(log n), у вырожденного дерева O(n).
len: O(1). Обходы: O(n) времени и O(n) памяти на возвращаемый список,
плюс стек O(h). Основные операции написаны без рекурсии, поэтому длинная
цепочка узлов не вызывает RecursionError. Это не устраняет медленную
работу вырожденного дерева.

## Как объяснить удаление

1. Найти узел и его родителя.
2. Если детей нет — отключить узел.
3. Если ребёнок один — подключить его вместо узла.
4. Если детей два — перенести в узел максимум левого поддерева,
   затем удалить прежний узел с этим максимумом. Правого ребёнка у него нет.

Здесь выбран максимум слева, чтобы сохранить правило повторов.
Замена минимумом справа без дополнительной обработки могла бы оставить
равное значение в правом поддереве и нарушить строгое неравенство.

## Тесты

unittest входит в стандартную библиотеку Python. Каждый test_* — отдельная
проверка. assertEqual сравнивает результат с ожидаемым; assertTrue и
assertFalse проверяют логические результаты; assertRaises — исключения.

Проверяются пустое дерево, вставка, поиск, все случаи удаления, повторы,
минимум и максимум, три обхода, строки, цепочки из 1500 узлов и 500
воспроизводимых случайных операций. После изменений проверяются значения,
размер, отсутствие циклов и правило BST с границами для всего поддерева.
Случайные операции сравниваются с независимой моделью на обычном списке.
